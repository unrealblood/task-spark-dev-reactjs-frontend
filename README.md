# Task Spark (Vite + ReactJS)

Task Spark is simply a Todo Full-Stack web application project which improves the productivity of the user by allowing a user to enter list of tasks, mark them completed, edit task, delete task, etc.

This project is only the frontend part of Task Spark. Below is a list of backends of this project built with different technologies:

- NodeJS and MongoDB: [https://github.com/unrealblood/task-spark-dev-nodejs-mongodb-backend](https://github.com/unrealblood/task-spark-dev-nodejs-mongodb-backend)
- NodeJS and MySQL: [https://github.com/unrealblood/task-spark-dev-nodejs-mysql-backend](https://github.com/unrealblood/task-spark-dev-nodejs-mysql-backend)
- NodeJS and PostgreSQL: [https://github.com/unrealblood/task-spark-dev-nodejs-postgresql-backend](https://github.com/unrealblood/task-spark-dev-nodejs-postgresql-backend)
- FastAPI and Python: [https://github.com/unrealblood/task-spark-dev-fastapi-python-backend](https://github.com/unrealblood/task-spark-dev-fastapi-python-backend)
